## 💻 Sobre o projeto

AluraBook é uma aplicação web estática que simula uma livraria online, onde o usuário pode navegar por categorias, conferir novos lançamentos, mais vendidos, tópicos visitados recentemente e se inscrever para receber novidades.

O projeto foi desenvolvido para exercitar:

- Estruturação semântica com HTML5
- Estilização modularizada e responsiva com CSS3
- Integração do carrossel com a biblioteca Swiper.js
- Acessibilidade básica com menus responsivos via checkbox toggle
- Deploy estático usando a plataforma Vercel

---

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3 (com variáveis, modularização e responsividade)
- JavaScript (para inicializar o Swiper.js)
- [Swiper.js](https://swiperjs.com/)
- Deploy no [Vercel](https://vercel.com/)
